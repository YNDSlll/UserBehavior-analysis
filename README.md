# 电商用户行为分析项目

## 项目
基于阿里天池 UserBehavior 数据集（采样 100 万行）的用户行为分析：
清洗 → 漏斗与 EDA → RFM + K-Means 分层 → 流失预测（逻辑回归 / XGBoost）→ Streamlit 展示。

## 目录结构
```
data/
  raw/        原始全量数据 UserBehavior.csv（3.4GB，只读）
  sample/     采样数据 UserBehavior_1m.csv（前 100 万行）
  processed/  清洗后数据 UserBehavior_clean.csv、用户分层 UserBehavior_rfm.csv
notebooks/    分析代码
output/
  charts/     图表
  reports/    报告与导出结果
```
