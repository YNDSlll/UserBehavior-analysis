定位：数据分析求职简历项目（可复用为毕设选题三）· 教练模式：你动手，我检查

项目最终形态（先知道终点长什么样）

一份能直接写进简历的完整项目："基于百万级电商用户行为数据的用户分层与流失预测分析"——含数据清洗、转化漏斗分析、RFM 用户分层、流失预测模型、结论建议、可视化展示。面试官问任何一层你都答得上来。

六个里程碑

M0环境搭建 + 数据到手 （当前任务）

  • 你做：注册/登录阿里天池，下载 UserBehavior 数据集；本地建好项目文件夹和 Python 环境；用 pandas 成功读进数据并打印前 5 行。
  • 目标：让数据在你的电脑里"活"起来。
验收：能报出数据的行数、列名、每列的数据类型，并说清每一列的业务含义。
常见坑：数据文件很大，别用 Excel 打开（会卡死）；读文件时注意分隔符和是否有表头。

M1数据清洗与预处理

  • 你做：处理重复值、时间戳转换（这份数据时间是 Unix 时间戳，要转成北京时间）、异常值筛查（时间范围外的数据）、字段含义校验。
  • 产出：一个干净的 DataFrame + 一段"清洗前后数据量对比"的记录。
验收：能说出你删了什么、为什么删、删掉多少、不删会怎样。
常见坑：Unix 时间戳直接展示被面试官一眼看穿；清洗前后行数没记录，写报告时说不清。

M2探索性分析（EDA）+ 转化漏斗

  • 你做：PV/UV 计算、按天/按小时的行为趋势图、点击→加购→收藏→购买转化漏斗。
  • 产出：4~6 张有业务解读的图（每张图配一句"这张图说明了什么"）。
验收：能口头讲出 3 个从数据里发现的、有业务含义的现象（比如活跃高峰时段、流失最严重的漏斗环节）。
常见坑：只出图不解读 = 白做；图没有标题和坐标轴标签 = 面试减分。

M3RFM 模型 + K-Means 用户分层

  • 你做：基于数据构造 R（最近购买间隔）、F（购买频次）、M（该数据集无金额，用行为量替代并说明）指标；用 K-Means 聚类分层；给每层用户起业务名字并提运营建议。
验收：能解释为什么 K 值选这个数（肘部法/轮廓系数），每层用户的特征和应对策略。
常见坑：不做标准化直接聚类（结果失真）；K 值拍脑袋选。

M4流失定义 + 流失预测模型

  • 你做：定义"流失"（如观察期后 N 天无任何行为的用户，要能自圆其说）；构造特征（活跃天数、行为构成、近 7 天行为数等）；训练逻辑回归 + XGBoost，对比效果；用特征重要性解释"什么样的用户容易流失"。
验收：能讲清流失定义的业务依据、类别不平衡怎么处理、为什么看召回率/F1 而不只看准确率。
常见坑：数据穿越（用了未来的信息预测过去）；只报一个准确率数字。

M5成果包装：报告 + 可视化 + 面试话术

  • 你做：用 Streamlit 把核心图表和结论搭成一个可演示的小页面；写一页项目总结（背景→做法→结论→建议）；准备面试问答（项目难点、为什么选这个模型、业务价值）。
验收：不看稿、5 分钟把项目从背景讲到结论；简历上能用 3 行把这个项目写清楚。
